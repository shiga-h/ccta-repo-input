# CCTA所見入力アプリ

冠動脈CT（CCTA）所見のスマホ入力→メール起動を行うクライアント完結Webアプリです。

## 機能

- 基本情報入力（解析者、症例識別コード、石灰化スコア）
- 血管所見の繰り返し入力（血管、No.、location、狭窄率、性状、特殊所見）
- 1行ずつプレビューに追加
- 「Gmailで作成」ボタンでメール起動
- iOS/Android両対応（GmailアプリURLスキーム→mailtoの順でフォールバック）
- データは端末内のみ（localStorageドラフト保存）

## 所見出力ルール

- 性状あり + 特殊所見あり → `#1：25% 石灰化プラーク（PR）`
- 性状なし + 特殊所見あり → `#8：PR（＋）`
- 空欄項目はスキップ

## 技術スタック

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Zustand + localStorage（自動保存）

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build
```

## 使用方法

1. ブラウザでアプリを開く
2. 基本情報を入力
3. 血管所見を選択して「1行追加」
4. 繰り返して所見を追加
5. 「Gmailで作成」でメール送信
