# CCTA所見入力アプリ（QRコード版）

冠動脈CT解析結果をスマホで入力し、QRコードを生成。電子カルテ端末のバーコードリーダーで読み取り、Excelテンプレートに自動入力するWebアプリです。

## 機能

- スマートフォンでフォーム入力（PWA対応）
- 血管所見の構造化入力（血管・セグメント・狭窄率・性状など）
- 音声入力対応（フリーテキスト入力時）
- 入力データからQRコードを自動生成
- バーコードリーダー（キーボードウェッジモード）でExcelに直接入力
- ローカルストレージによる自動保存機能

## 運用フロー

1. スマートフォンでアプリを開き、解析結果を入力
2. 「QRコード生成」ボタンをタップ
3. 電子カルテ端末でExcelテンプレートを開き、入力先セルを選択
4. バーコードリーダーでQRコードをスキャン
5. データが縦方向に自動入力される

## QRコードの仕様

- 格納データ: 解析結果を改行（CRLF）区切りで連結したテキスト
- 出力形式: 
  ```
  ＜冠動脈＞（担当技師：解析者名）
  石灰化スコア：xxx
  LAD #7 prox：75% 混合プラーク
  ...
  ```
- エラー訂正レベル: M（15%）
- データサイズ: 約300-800バイト（QRコード容量内）

## バーコードリーダーの要件

- QRコード（2Dバーコード）読み取り対応
- キーボードウェッジモード（読み取り内容をキーボード入力としてエミュレート）
- 改行コード（CRLF）をEnterキーとして送信

## 主な機能

### 血管所見入力
- 血管選択（RCA, LAD, Cx, LMT等）
- セグメントNo.（#1〜#15）
- Stent留置の有無
- 部位（prox, mid, dist）
- 狭窄率（25%, 50%, 75%, 90%, 99%, 100%）
- 性状（石灰化プラーク、混合プラーク等）
- 特殊所見（PR, MB, ectasia等）
- フリーテキスト入力（音声認識対応）

### 基本情報
- 解析者名
- 石灰化スコア
- 定型文挿入（モーションアーチファクト、有意狭窄なし）

### その他
- 自動保存機能（ON/OFF切替可能）
- リアルタイムプレビュー
- 所見の追加・削除
- 全クリア機能

## 注意事項

- 入力データはローカルストレージに保存されます（自動保存が有効な場合）
- PHI（患者情報）は端末内にのみ保存され、サーバーには送信されません
- QRコードの読み取りには、対応するバーコードリーダーが必要です
